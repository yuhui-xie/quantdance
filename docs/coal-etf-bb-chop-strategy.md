# 煤炭ETF 周线布林+CHOP 策略（`coal_etf_bb_chop`）

单标的、周线频率的独立策略：用布林带判断位置，用 CHOP(28) 判断行情性质，
在「趋势市跟随 / 震荡市超跌」两种模式间切换。与 `coal_etf_mfi` 是**两个独立
策略**，互不融合。

## 一、数据与频率口径

- 日线 OHLCV 经 `resample("W-FRI")` 聚合为周线（open=首、high=最高、low=最低、
  close=末、volume=求和）。
- 周线只使用**已经走完**的那一根：交易日 `d` 取「完成日 ≤ d」的最后一根周线。
  周线完成日取该 ISO 周内最后一个真实交易日（节假日周五休市时不会把未走完的周
  当成已完成）。周五收盘时当周周线刚好完成，因此周五收盘即可使用当周值，不存在
  未来函数。
- 信号是**状态型**的，在当日收盘价成交：处于「允许做多」状态时每天输出买入
  （空仓时买入一次，持仓时引擎忽略）；触发退出时输出卖出。

## 二、指标定义

| 指标 | 口径 |
| --- | --- |
| 布林中轨 | 周收盘价 `bb_period`（默认 20）周简单均线 |
| 布林上/下轨 | 中轨 ± `bb_num_std`（默认 2.0）× 同窗口总体标准差（`ddof=0`） |
| CHOP | `100 × log10(ΣTR_n / (HH_n − LL_n)) / log10(n)`，`n=chop_period`（默认 28 周） |

## 三、信号规则

以最新已完成周线判定：

| CHOP(28) | 模式 | 做多条件（`long_ok`） | 退出条件（`weekly_exit`） |
| --- | --- | --- | --- |
| `< chop_trend_threshold`（默认 40.7） | 趋势市 | 周收盘 **>** 布林中轨 | 周收盘 **<** 布林中轨 |
| `> chop_range_threshold`（默认 59.3） | 震荡市 | 周内最低价 **≤** 布林下轨（超跌） | 周内最高价 **≥** 布林上轨（超买） |
| 两者之间 | 中性区 | 视 `neutral_action` | 视 `neutral_action` |

`neutral_action`：

- `flat`（默认）：只要不处于明确的多头状态就退出。震荡市「触及下轨」买入后，
  若下一周不再满足超跌条件即离场；
- `hold`：中性区保持现有仓位，只在趋势市跌破中轨 / 震荡市触及上轨时卖出。

同日买卖同时成立时**卖出优先**。

### 关于 CHOP 阈值默认值

CHOP 以 `log10(n)` 归一化，随机游走大致锚定在 50；周期越长，围绕 50 的分布越窄。
常见文档里的 `38.2/61.8` 是 **n=14** 的经验阈值。换到 **n=28** 时按 log 周期等比
缩放：`50 − (50−38.2) × log10(14)/log10(28) ≈ 40.7`，镜像即 `59.3`，以保持与经典
口径相近的「趋势 / 震荡」稀有度。

若直接沿用 `38.2/61.8`，515220 的周线 CHOP(28) 几乎永远落在中性区，`flat` 模式下
策略会完全空仓。

## 四、参数

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `bb_period` | 20 | 周线布林中轨窗口（周） |
| `bb_num_std` | 2.0 | 布林带标准差倍数 |
| `chop_period` | 28 | 周线 CHOP 窗口（周） |
| `chop_trend_threshold` | 40.7 | 低于该 CHOP 视为趋势市 |
| `chop_range_threshold` | 59.3 | 高于该 CHOP 视为震荡市 |
| `neutral_action` | `flat` | 中性区处理：`flat` 不持仓 / `hold` 保持仓位 |

## 五、示例

```bash
cd backend
python -m app.script backtest --strategy coal_etf_bb_chop --symbol 515220 \
  --start-date 2021-01-01 --end-date 2026-09-18
```

请求文件：`examples/batch_test/backtest_coal_etf_bb_chop.json`。

## 六、回测特征（如实记录）

以 515220 本地缓存日线、2021-01-01 ~ 2026-09-18 为区间：

| 口径 | 总收益 | 年化 | 最大回撤 | 回合数 |
| --- | --- | --- | --- | --- |
| `neutral_action=flat`（默认） | -9.6% | -1.8% | 24.9% | 4 |
| `neutral_action=hold` | -1.7% | -0.3% | 33.2% | 1 |

同期买入持有约 +117%。该策略在这一区间明显跑输：周线 CHOP(28) 的趋势市窗口很短，
布林中轨的信号在煤炭 ETF 上反复被打脸。按项目约定，规则按口径落地，不按回测结果
反向优化参数；如需改进，优先从 CHOP 阈值、布林窗口或 `neutral_action` 入手，并
在其他区间/标的上复核。
